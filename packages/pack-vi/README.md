# @determask/pack-vi

Vietnamese locale pack — CCCD, CMND, MST, BHYT/BHXH, phones, names, addresses.

**Status: skeleton.** The pack loads into the engine but ships no
recognizers yet. Its first recognizers arrive in their own pull request;
this README then lists what it detects, the primary source behind each
validator, and what is still missing.

Part of [determask](../../README.md) — deterministic PII masking for free
text. Not published to npm yet.
